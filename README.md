# Wordly · 작은 사전

Reader to Writer 르완다 × 장흥 3–6학년 워크북용 영한·한영 사전입니다.

영어·한국어·한글 발음·활용형·철자 오류를 검색합니다. 본문, 활동 지시문, 학생의 예상 답변에 필요한 확장 표현과 예문을 먼저 보여줍니다. 찾기 또는 Enter를 누르면 MyMemory API로 일반 영한·한영 번역도 함께 조회합니다. 입력 중에는 로컬 검색만 실행합니다. 검색어는 일반 번역 조회 시 MyMemory에 전달됩니다. 외부 서비스 연결과 이용 한도에 따라 일반 번역이 제한될 수 있으며 실패해도 워크북 결과는 유지됩니다. API 키는 필요하지 않습니다.

`index.html`을 열거나 정적 서버로 실행하세요. GitHub Pages는 저장소의 main 브랜치 루트에서 서비스합니다.

`node verify.cjs`로 검색을 검증할 수 있습니다. `data.js`에서 검색 단어·뜻·별칭을, `examples.js`에서 예문을 수정할 수 있습니다. 워크북 전체 원문이나 학생 개인정보는 저장하지 않습니다. 발음은 지원하는 브라우저의 음성 합성 기능을 사용합니다. 웹 폰트 연결이 없어도 시스템 글꼴로 표시됩니다.
